- **The world editor is the dev server's alone, flies the camera with the hidden body as the world's anchor, and everything that stands for the character reads the return point, never the camera** (Map-maker I, wave 1: `src/editor/`, `src/ui/editorWindow.ts`, `editorBar.ts`, `editorMarks.ts`, `libraryUi.ts`, `tools/swg/library.mjs`, `W1-notes.md` in the pass's folder). Point mode is four hand-overs in `main.ts` (the lock's `lost` clause, the canvas click, `mouseHeldElsewhere`, the drained wheel) and never sets `captured`. And **the heightfield is a fixed collider**, so near the anchor the ground answers the aim as `still` and the terrain's march answers only past the colliders. The aim makes nothing a frame (0.045 B over twelve processes at once, from 164 scavenges in 50,000 frames) once three more boxing traps were found: a number handed across a call the compiler does not build in goes in a kept record (the ray, the sample, the cast's answer, the walk's rectangle, the march's tune handed whole); **a field that will hold a fraction must start as one** (0.5, or NaN for a place), since a field that starts as a small integer boxes every fraction written into it afterwards; and a loop's local that turns from an integer to a fraction is a `Float64Array` register. The ghost is built as `addToTier` builds a placement (an instanced mesh of one per primitive, a building's cells left out), prepared before it is shown, and left behind on the same geometry and materials until the row's own meshes are built, so a placement never blinks.
